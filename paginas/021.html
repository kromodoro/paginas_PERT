Certo!

    Os eventos devem ter uma sequência lógica. Há uma relação definida de sequência entre os eventos de uma rede PERT. Os eventos dependem um do outro como Evento 1, “Relatório iniciado”; Evento 2, “Relatório terminado” - uma relação lógica é obedecida.

    Os eventos podem ser representados numa rede PERT por círculos, ovais, quadrados, ou qualquer outra figura geométrica. Neste texto usaremos círculos para representar os eventos. É importante, no entanto, que os eventos estejam em uma sequência lógica.
